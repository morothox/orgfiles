* Qualitative Analytik:   
** Was ist drinnen? 
*** 1.1 Hinweis und Nachweis
    *Versuch: Gasaustreibung mit Salzsäure (Vorprobe auf Uhrgläsern)*

    #+BEGIN_SRC text
           Pipette                              Pipette
            [   ]                                [   ]
             | |                                  | |
             | | (verd. HCl)                      | | (verd. HCl)
             | |                                  | |
              ▼                                    ▼
              : (Tropfen)                          : (Tropfen)
              
          SO₂ ↑ (stechender Geruch)            CO₂ ↑ (geruchlos)
          ░ ░ ░                                ○  ○  ○ (Aufschäumen)
        \_____.:::._____/                    \_____.:::._____/
        (  Sulfit-Salz  )                    ( Carbonat-Salz )
         \ (z.B. Na₂SO₃)/                     \ (z.B. Na₂CO₃)/
          `------------'                       `------------'
            Uhrglas 1                            Uhrglas 2
    #+END_SRC

    - *Durchführung:*
      Auf zwei Uhrgläser wird jeweils eine kleine Spatelspitze Salz gegeben (Uhrglas 1: Sulfitsalz, z. B. Na₂SO₃; Uhrglas 2: Carbonatsalz, z. B. Na₂CO₃). Anschließend werden vorsichtig mit einer Pipette einige Tropfen verdünnte Salzsäure (HCl) direkt auf die Salzkörner getropft. Vorsichtiges Zufächeln mit der Hand für die Geruchsprobe.

    - *Beobachtung:*
      - *Uhrglas 1 (Sulfit):* Schwaches bis mäßiges Aufschäumen/Bläschenbildung. Es entsteht ein stechender, schwefliger Geruch (nach verbranntem Streichholz bzw. Schwefeldioxid SO₂).
      - *Uhrglas 2 (Carbonat):* Heftiges Aufbrausen und Sprudeln (Brauseeffekt). Das entweichende Gas (CO₂) ist vollkommen geruchlos.

    - *Erklärung & Reaktionsgleichungen:*
      Die Salzsäure ist als starke Säure fähig, die schwächeren und flüchtigen Säuren (schweflige Säure H₂SO₃ bzw. Kohlensäure H₂CO₃) aus ihren Salzen zu verdrängen. Die entstehenden instabilen Säuren zerfallen sofort in Wasser und das jeweilige Gas:
      - *Sulfit:*
        SO₃²⁻ + 2 H₃O⁺ -> [H₂SO₃ + 2 H₂O] -> SO₂↑ + 3 H₂O
        (als Stoffgleichung: Na₂SO₃ + 2 HCl -> 2 NaCl + H₂O + SO₂↑)
      - *Carbonat:*
        CO₃²⁻ + 2 H₃O⁺ -> [H₂CO₃ + 2 H₂O] -> CO₂↑ + 3 H₂O
        (als Stoffgleichung: Na₂CO₃ + 2 HCl -> 2 NaCl + H₂O + CO₂↑)

    - *Bedeutung für "Hinweis vs. Nachweis":*
      - *Hinweis (Vorprobe):* Das Sprudeln und der Geruch geben einen ersten schnellen Anhaltspunkt darüber, was in der Probe stecken könnte (Bläschen ohne Geruch deutet auf CO₃²⁻ hin, Bläschen mit Schwefelgeruch auf SO₃²⁻).
      - *Nachweis:* Ein Hinweis ist noch kein sicherer Beweis (Gasentwicklung ist relativ unspezifisch, Geruch ist subjektiv). Erst eine spezifische Nachweisreaktion belegt das Anion zweifelsfrei:
        - Für Carbonat: Leiten des Gases in Kalkwasser/Barytwasser -> weiße Trübung (CaCO₃ bzw. BaCO₃).
        - Für Sulfit: Entfärbung einer violetten Kaliumpermanganatlösung (KMnO₄, Redoxreaktion) oder Nachweis als Bariumsulfat nach Zugabe von H₂O₂.
*** 1.2 Nachweis von Sulfat-Ionen
    *Versuch: Fällungsreaktion mit Bariumchlorid*

    #+BEGIN_SRC text
           Pipette                              Pipette
            [   ]                                [   ]
             | |                                  | |
             | | (BaCl₂-Lösung)                  | | (BaCl₂-Lösung)
             | |                                  | |
              ▼                                    ▼
              : (Tropfen)                          : (Tropfen)
              
          ⚪ ⚪ ⚪ (milchig-weiß)                ⚪ ⚪ ⚪ (milchig-weiß)
        ░░░░░░░░░                            ░░░░░░░░░
        \_____.:::._____/                    \_____.:::._____/
        (  Sulfat-Lösung )                   ( Sulfit-Lösung )
         \ (z.B. Na₂SO₄) /                    \ (z.B. Na₂SO₃) /
          `------------'                       `------------'
            Reagenzglas 1                        Reagenzglas 2
    #+END_SRC

    - *Durchführung:*
      Auf zwei Reagenzgläser werden jeweils ca. 2 ml wässrige Lösung gegeben (Reagenzglas 1: Sulfatlösung, z. B. Na₂SO₄; Reagenzglas 2: Sulfitlösung, z. B. Na₂SO₃). Anschließend werden mit einer Pipette einige Tropfen verdünnte Bariumchlorid-Lösung (BaCl₂) hinzugegeben.

    - *Beobachtung:*
      - *Reagenzglas 1 (Sulfat):* Es bildet sich sofort eine milchig-weiße Trübung (feiner weißer Niederschlag von BaSO₄), die auch beim Stehen nicht verschwindet.
      - *Reagenzglas 2 (Sulfit):* Es bildet sich ebenfalls sofort eine milchig-weiße Trübung (feiner weißer Niederschlag von BaSO₃).
    - *Erklärung & Reaktionsgleichungen:*
      Sowohl Sulfat- als auch Sulfit-Ionen reagieren mit Barium-Ionen zu schwer löslichen weißen Niederschlägen:
      - *Sulfat:*
        SO₄²⁻ + Ba²⁺ -> BaSO₄↓
        (als Stoffgleichung: Na₂SO₄ + BaCl₂ -> BaSO₄↓ + 2 NaCl)
      - *Sulfit:*
        SO₃²⁻ + Ba²⁻ -> BaSO₃↓
        (als Stoffgleichung: Na₂SO₃ + BaCl₂ -> BaSO₃↓ + 2 NaCl)

      -> *Die milchig-weiße Trübung zeigt an, dass Sulfat- oder Sulfit-Ionen vorliegen!*

    - *Störung:*
      Auch Sulfit-Ionen (SO₃²⁻) geben mit Ba²⁺ einen weißen Niederschlag (BaSO₃). Zur Unterscheidung vorher mit verdünnter Salzsäure ansäuern: Sulfite entwickeln dabei SO₂ (stechender Geruch), Sulfate bleiben unverändert.
*** 1.3 Nachweis von Carbonat-Ionen (Kalkwasserprobe)
    *Versuch: Gasaustreibung und Nachweis mit Kalkwasser*

    #+BEGIN_SRC text
      Reagenzglas 1 (Entwickler)              Reagenzglas 2 (Vorlage)
                 ┌───┐                                  ┌───┐
      Stopfen -> │===│                                  │   │
                 │ │ └──────┬───────────────────────┐   │   │
                 │ │        │ Ableitungsrohr        │   │   │
                 │ │        │ (oder Gärröhrchen)    │   │ │ │
                 │ │        │                       │   │ │ │
                 │          │                       │   │ ▼ │ CO₂ perlt ein
                 │          │                       │   │. .│
                 │   o  o   │ Gasentwicklung        │   │. .│ klares Kalkwasser
                 │~~~~~~~~~~│ (CO₂ ↑)               │   │~~~│ Ca(OH)₂ -> trübt
                 │. . . . . │ Probe (CO₃²⁻) + HCl   └───┴───┘ sich weiß (CaCO₃ ↓)
                 └──────────┘
    #+END_SRC

    - *Geräte & Chemikalien:*
      Zwei Reagenzgläser, durchbohrter Stopfen mit abgewinkeltem Glasrohr (alternativ: aufgesetztes Gärröhrchen), Pipette, Spatel; carbonathaltige Probe (z. B. Na₂CO₃ oder CaCO₃), verdünnte Salzsäure (HCl), frisch filtriertes, klares Kalkwasser (gesättigte Ca(OH)₂-Lösung) bzw. Barytwasser (Ba(OH)₂).

    - *Durchführung:*
      1. Eine Spatelspitze der Carbonatprobe wird in Reagenzglas 1 vorgelegt und mit etwa 2–3 ml verdünnter Salzsäure versetzt.
      2. Das Glas wird sofort mit dem Stopfen verschlossen, dessen Ableitungsrohr bis auf den Grund von Reagenzglas 2 (gefüllt mit ca. 3 ml Kalkwasser) taucht.
      3. Zur Beschleunigung kann das Entwicklerglas leicht geschwenkt oder vorsichtig erwärmt werden.

    - *Beobachtung:*
      - In Reagenzglas 1 setzt sofort heftiges Aufschäumen und Bläschenbildung ein (farbloses, geruchloses Gas).
      - In Reagenzglas 2 bilden sich Gasblasen und das zuvor vollkommen klare Kalkwasser trübt sich nach wenigen Sekunden milchig-weiß ein.
      - /Zusatzbeobachtung (bei längerem Einleiten):/ Leitet man über längere Zeit weiter CO₂ ein, verschwindet die Trübung wieder und die Lösung wird wieder vollständig klar.

    - *Erklärung & Reaktionsgleichungen:*
      - *1. Schritt: Verdrängung und Gasbildung (Entwicklerglas)*
        Salzsäure verdrängt die schwache Kohlensäure aus ihren Salzen, welche sofort zu Wasser und Kohlenstoffdioxid zerfällt:
        CO₃²⁻ + 2 H₃O⁺ -> [H₂CO₃ + 2 H₂O] -> CO₂↑ + 3 H₂O
        (bzw. als Stoffgleichung: Na₂CO₃ + 2 HCl -> 2 NaCl + H₂O + CO₂↑)

      - *2. Schritt: Nachweisreaktion (Fällungsreaktion im Kalkwasser)*
        Das eingeleitete Kohlenstoffdioxid reagiert mit den Calcium- und Hydroxidionen des Kalkwassers zu schwer löslichem Calciumcarbonat (Kalk), das als feiner weißer Niederschlag ausfällt:
        CO₂ + Ca²⁺ + 2 OH⁻ -> CaCO₃↓ + H₂O
        -> *Die weiße Trübung beweist zweifelsfrei das Vorliegen von Carbonat-Ionen!*
        (Hinweis: Mit Barytwasser Ba(OH)₂ fällt entsprechend weißes Bariumcarbonat BaCO₃↓ aus, was wegen geringerer Löslichkeit noch empfindlicher ist.)

      - *3. Schritt: Wiederauflösung bei CO₂-Überschuss (Kalk-Kohlensäure-Gleichgewicht)*
        Wird weiterhin CO₂ eingeleitet, reagiert das unlösliche Calciumcarbonat zu leicht löslichem Calciumhydrogencarbonat weiter:
        CaCO₃↓ + CO₂ + H₂O ⇌ Ca²⁺ + 2 HCO₃⁻
        (Dies entspricht dem chemischen Prozess der Entstehung von Karstformen und Tropfsteinhöhlen.)
*** 1.4 Nachweis von Fällungsreaktion
    Bsp: Nachweis von Sulfat-Ionen mit Bariumchlorid-Lösung
    Voraussetzungen: Testsubstanz und Nachweis-Reagenz müssen löslich sein.
    Vorgänge auf Teilchenebene

    *Versuch: Fällungsreaktion mit Bariumchlorid*

    #+BEGIN_SRC text
              Pipette
               [   ]
                | |
                | | (BaCl₂-Lösung)
                | |
                 ▼
                 : (Tropfen)

           ⚪ ⚪ ⚪ (milchig-weiße Trübung = BaSO₄ ↓)
         ░░░░░░░░░░░░░░░░░░░░
         \__________________/
         (  Sulfat-Lösung   )
          \ (z.B. Na₂SO₄)  /
           `--------------'
             Reagenzglas
    #+END_SRC

    - *Geräte & Chemikalien:*
      Reagenzglas, Pipette, Spatel; Sulfat-Lösung (z. B. Na₂SO₄), verdünnte Bariumchlorid-Lösung (BaCl₂).

    - *Durchführung:*
      Etwa 2 ml der wässrigen Sulfat-Lösung werden in ein Reagenzglas gegeben. Anschließend werden mit der Pipette einige Tropfen verdünnte Bariumchlorid-Lösung hinzugetropft.

    - *Beobachtung:*
      Es bildet sich sofort eine milchig-weiße Trübung (feiner weißer Niederschlag von BaSO₄), die auch beim Stehen nicht verschwindet.

    - *Vorgänge auf Teilchenebene (Mikroebene):*
      #+BEGIN_SRC text
        gelöst (Ionen frei beweglich)      Fällung (Ionen verbinden sich)

         Na⁺      SO₄²⁻                        Na⁺     Na⁺
            ↘    ↙                    + Ba²⁺      ▓▓▓▓
         Na⁺   SO₄²⁻        ──────►              ▓▓▓▓  BaSO₄ ↓
            ↘    ↙                             ▓▓▓▓  (unlöslich,
         SO₄²⁻   Na⁺                            Na⁺   fällt aus)

        frei beweglich        ──►     fest, geordnet (Niederschlag)
      #+END_SRC
      - In der Lösung liegen die Ionen frei und getrennt vor: Na⁺ und SO₄²⁻ umgeben von Wasserteilchen.
      - Gibt man BaCl₂ dazu, liegen auch Ba²⁺ und Cl⁻ als freie Ionen vor.
      - Treffen Ba²⁺- und SO₄²⁻-Ionen zusammen, ziehen sich die entgegengesetzten Ladungen an und bilden ein Gitter (Ionenkristall). BaSO₄ ist schwer löslich, deshalb überschreitet es das Löslichkeitsprodukt und fällt als Feststoff aus.
      - Cl⁻ und Na⁺ bleiben gelöst („Zuschauer-Ionen"), sie sind gut löslich.

    - *Erklärung & Reaktionsgleichungen:*
      Sulfat-Ionen reagieren mit Barium-Ionen zu schwer löslichem Bariumsulfat:
      - *Ionengleichung:*
        SO₄²⁻ + Ba²⁺ -> BaSO₄↓
      - *Stoffgleichung:*
        Na₂SO₄ + BaCl₂ -> BaSO₄↓ + 2 NaCl

      -> *Die milchig-weiße Trübung zeigt an, dass Sulfat-Ionen vorliegen!*

    - *Nachweis vs. Störung:*
      - BaSO₄ ist der Nachweis: Der Niederschlag ist *säurebeständig*, er löst sich auch nach Zugabe von verdünnter HCl nicht auf.
      - *Störung:* Auch Sulfit- (SO₃²⁻) und Carbonat-Ionen (CO₃²⁻) geben mit Ba²⁺ weiße Niederschläge (BaSO₃ bzw. BaCO₃). Diese lösen sich aber in Säure (SO₂↑ bzw. CO₂↑). Ansäuern vor der BaCl₂-Zugabe beseitigt die Störung.
    
*** 1.5 Nachweis von Halogeniden Versuch: 
    Lösung eines halogenit-haltigen-salzes kaliumbromid
    Voraussetzungen: Testsubstanz und Nachweis-Reagenz müssen löslich sein.
    Vorgänge auf Teilchenebene

    *Versuch: Fällungsreaktion mit Silbernitrat*

    #+BEGIN_SRC text
              Pipette
               [   ]
                | |
                | | (AgNO₃-Lösung)
                | |
                 ▼
                 : (Tropfen)

           ⊙ ⊙ ⊙ (hellgelber, cremefarbener Niederschlag = AgBr ↓)
         ░░░░░░░░░░░░░░░░░░░░
         \__________________/
         ( Halogenid-Lösung )
          \ (z.B. KBr)      /
           `--------------'
             Reagenzglas
    #+END_SRC

    - *Geräte & Chemikalien:*
      Reagenzglas, Pipette, Spatel; Kaliumbromid-Lösung (KBr), verdünnte Silbernitrat-Lösung (AgNO₃), verdünnte Salpetersäure (HNO₃) zum Ansäuern.

    - *Durchführung:*
      Etwa 2 ml der wässrigen Kaliumbromid-Lösung werden in ein Reagenzglas gegeben. Vorher wird mit einigen Tropfen verdünnter Salpetersäure angesäuert, anschließend werden mit der Pipette einige Tropfen Silbernitrat-Lösung hinzugetropft. Das Reagenzglas wird dunkel gestellt bzw. nicht unnötig dem Licht ausgesetzt.

    - *Beobachtung:*
      Es bildet sich sofort ein hellgelber, cremefarbener bis gelblich-weißer Niederschlag (Silberbromid AgBr). Der Niederschlag löst sich in verdünnter Salpetersäure nicht auf. Bei längerem Stehen im Licht färbt er sich allmählich nach, er wird gräulich bis dunkel.

    - *Vorgänge auf Teilchenebene (Mikroebene):*
      #+BEGIN_SRC text
        gelöst (Ionen frei beweglich)      Fällung (Ionen verbinden sich)

         K⁺       Br⁻                          K⁺      K⁺
            ↘    ↙                    + Ag⁺      ▓▓▓▓
         K⁺    Br⁻          ──────►              ▓▓▓▓  AgBr ↓
            ↘    ↙                             ▓▓▓▓  (schwer löslich,
         Br⁻      K⁺                           NO₃⁻   fällt aus)

        frei beweglich        ──►     fest, geordnet (Niederschlag)
      #+END_SRC
      - In der Lösung liegen K⁺ und Br⁻ frei und getrennt vor.
      - Nach Zugabe von AgNO₃ liegen zusätzlich Ag⁺ und NO₃⁻ als freie Ionen vor.
      - Ag⁺ und Br⁻ ziehen sich wegen ihrer entgegengesetzten Ladungen an und lagern sich zu einem Ionengitter an. AgBr ist schwer löslich, es wird also schnell mehr AgBr gebildet, als sich lösen kann, und der Überschuss fällt als Feststoff aus.
      - K⁺ und NO₃⁻ bleiben gelöst („Zuschauer-Ionen").

    - *Erklärung & Reaktionsgleichungen:*
      Silber-Ionen reagieren mit Halogenid-Ionen zu schwer löslichen Silberhalogeniden:
      - *Ionengleichung:*
        Ag⁺ + Br⁻ -> AgBr↓
      - *Stoffgleichung:*
        AgNO₃ + KBr -> AgBr↓ + KNO₃

      -> *Der hellgelbe Niederschlag zeigt an, dass Bromid-Ionen vorliegen!*

    - *Nachweis vs. Störung:*
      - Die Farbe des Niederschlags unterscheidet die Halogenide: Chlorid gibt einen weißen (AgCl), Bromid einen hellgelben (AgBr) und Iodid einen gelben Niederschlag (AgI).
      - *Störung:* Auch Carbonat- und Sulfit-Ionen geben mit Ag⁺ einen weißen Niederschlag. Deshalb wird die Probe vorher mit verdünnter *Salpetersäure* angesäuert. Diese verdrängt CO₃²⁻ und SO₃²⁻, die Niederschläge können sich nicht mehr bilden. Auf keinen Fall mit Salzsäure ansäuern, weil man damit selbst Chlorid-Ionen in die Probe einbringt.
      - *Zusatz:* Die Silberhalogenide sind lichtempfindlich. Meist wird die Probe zusätzlich mit Ammoniak-Lösung geprüft, da sich AgCl leichter löst als AgBr.

*** 1.6 Nachweis durch Farbreaktion 
    Versuch: Ammonium-Nachweis (Kreuzprobe / Gasaustreibung mit Indikator-Farbreaktion)

    Voraussetzungen: Freisetzung von gasförmigem Ammoniak durch eine starke Base.
    Vorgänge auf Teilchenebene & Farbreaktion am Indikator

    *Versuch: Verdrängung von Ammoniak und Farbreaktion am Indikatorpapier*

    #+BEGIN_SRC text
      feuchtes Indikatorpapier (rot/gelb)
      wird an die Öffnung gehalten
              ┌───────────────┐
              │ ░░░░░░░░░░░░░ │  ◄── Farbumschlag nach INTENSIV BLAU (pH > 8)
              └───────┬───────┘
                      │
                      ▼
                  ┌───┴───┐
                  │       │
                  │       │
                  │  ↑ ↑  │ NH₃ ↑ (Ammoniakgas steigt auf,
                  │       │        stechender Geruch)
                  │~~~~~~~│
                  │. . . .│ Probe (z.B. NH₄Cl)
                  │. . . .│ + Natronlauge (NaOH)
                  └───────┘
                 Reagenzglas (evtl. leicht erwärmt)
    #+END_SRC

    - *Geräte & Chemikalien:*
      Reagenzglas (alternativ zwei Uhrgläser für die Kreuzprobe), Reagenzglasständer, Spatel, Pipette, Brenner/Wasserbad zum vorsichtigen Erwärmen; Ammonium-haltige Probe (z. B. Ammoniumchlorid NH₄Cl), verdünnte Natronlauge (NaOH, ca. 2 mol/l), demineralisiertes Wasser, Universalindikatorpapier (oder rotes Lackmuspapier).

    - *Durchführung:*
      1. Eine Spatelspitze der ammoniumhaltigen Probe wird in ein Reagenzglas gegeben und mit ca. 1–2 ml verdünnter Natronlauge (NaOH) versetzt (oder als Feststoff gemischt).
      2. Ein Streifen Universalindikatorpapier wird mit demineralisiertem Wasser angefeuchtet und vorsichtig über die Öffnung des Reagenzglases gehalten. Wichtig: Das Papier darf weder den Rand noch die Lösung berühren!
      3. Das Reagenzglas wird vorsichtig geschwenkt und bei Bedarf leicht handwarm erwärmt (nicht sieden lassen, damit keine Lauge verspritzt).
      4. Geruchsprobe: Durch vorsichtiges Zufächeln mit der Hand wird der Geruch über dem Glas geprüft.

    - *Beobachtung:*
      - Das angefeuchtete Indikatorpapier färbt sich an der Öffnung des Reagenzglases sofort intensiv **blau** bis blau-violett (stark basisches Milieu, pH ca. 9–11).
      - Es entsteht ein stechender, charakteristischer Geruch nach Ammoniak (Salmiakgeist).
      - An der kühleren oberen Glaswand schlägt sich feiner Flüssigkeitsbeschlag nieder.

    - *Vorgänge auf Teilchenebene (Mikroebene):*
      #+BEGIN_SRC text
        In der Lösung (Reagenzglas):          Im Wasserfilm des Papiers:

          NH₄⁺   +   OH⁻                       NH₃   +   H₂O
             ↘   ↙                                ↘   ↙
           [Protonenübergang]                  [Rückreaktion]
                   │                                  │
                   ▼                                  ▼
              NH₃ ↑  +  H₂O                      NH₄⁺  +  OH⁻
        (flüchtiges Gas entweicht)          (freie OH⁻ bewirken Farbumschlag
                                             des Indikatorfarbstoffs -> BLAU)
      #+END_SRC
      - In der Lösung liegen Ammonium-Ionen (NH₄⁺) und Hydroxid-Ionen (OH⁻) frei vor.
      - Hydroxid-Ionen sind wesentlich stärkere Basen als Ammoniak. Deshalb entreißt das OH⁻ dem NH₄⁺ ein Proton (H⁺): Es findet eine Säure-Base-Reaktion (Protolyse) statt.
      - Dabei entsteht ungeladenes, flüchtiges Ammoniakgas (NH₃), das aus der wässrigen Lösung nach oben entweicht.
      - Das aufsteigende NH₃ löst sich im Wasserfilm des feuchten Indikatorpapiers und reagiert dort erneut als Brønsted-Base: Es entreißt Wassermolekülen Protonen, wodurch wieder Hydroxid-Ionen (OH⁻) entstehen.
      - Die freien OH⁻-Ionen im Wasserfilm deprotonieren den Indikatorfarbstoff -> *Farbumschlag nach Blau*.

    - *Erklärung & Reaktionsgleichungen:*
      - *1. Schritt: Verdrängung des Ammoniaks durch die stärkere Base (Gasaustreibung):*
        Ammonium-Ionen wirken als schwache Brønsted-Säure, die Hydroxid-Ionen als starke Base:
        - *Ionengleichung:*
          NH₄⁺ + OH⁻ -> NH₃↑ + H₂O
        - *Stoffgleichung:*
          NH₄Cl + NaOH -> NH₃↑ + NaCl + H₂O

      - *2. Schritt: Farbreaktion am Indikatorpapier (Rückreaktion im Wasserfilm):*
        Das gasförmige Ammoniak löst sich im Wasser und reagiert alkalisch:
        - *Gleichgewichtsreaktion:*
          NH₃ + H₂O ⇌ NH₄⁺ + OH⁻

        -> *Der Farbumschlag des Indikators nach Blau beweist zweifelsfrei das Entweichen einer basischen flüchtigen Substanz (Ammoniak) und damit das Vorliegen von Ammonium-Ionen (NH₄⁺)!*

    - *Ergänzung: Spezifische chemische Farbreaktion mit Neßlers Reagenz:*
      - Gibt man zu einer neutralen bis schwach alkalischen Ammoniumprobe *Neßlers Reagenz* (alkalische Lösung von Kaliumtetraiodomercurat(II), K₂[HgI₄]), entsteht eine charakteristische **gelb-braune bis rotbraune Färbung** bzw. ein rotbrauner Niederschlag (Iodid der Millonschen Base, [Hg₂N]I · H₂O):
        2 [HgI₄]²⁻ + NH₄⁺ + 4 OH⁻ -> [Hg₂N]I · H₂O↓ + 7 I⁻ + 3 H₂O

      - *Häufigste Fehlerquelle:* Berührt das Indikatorpapier versehentlich die mit NaOH benetzte Reagenzglaswand oder gelangt ein Spritzer Lauge darauf, färbt es sich ebenfalls blau (falsch-positiver Befund durch die zugegebene Base). Das Papier darf deshalb strikt nur in den Gasraum gehalten werden.

    - *Geräte & Chemikalien:*
      3 Reagenzgläser im Reagenzglasständer, 3 Pipetten, Spatel;
      - Reagenzglas 1: Natriumsulfatlösung (Na₂SO₄, Positivkontrolle)
      - Reagenzglas 2: gelöste Testsubstanz (unbekannte Probe)
      - Reagenzglas 3: demineralisiertes/destilliertes Wasser (Blindprobe/Negativkontrolle)

    - *Durchführung:*
      1. Drei saubere Reagenzgläser werden beschriftet (1: Na₂SO₄ / Positiv, 2: Testsubstanz, 3: Blindprobe).
      2. In Reagenzglas 1 werden ca. 2 ml Natriumsulfatlösung, in Reagenzglas 2 ca. 2 ml der gelösten Testsubstanz und in Reagenzglas 3 ca. 2 ml destilliertes Wasser gegeben.
      3. Alle drei Gläser werden zunächst mit einigen Tropfen verdünnter Salzsäure (HCl) angesäuert, um eventuell störende Carbonat- oder Sulfitionen vorab zu zersetzen.
      4. Anschließend werden mit einer Pipette jeweils ca. 3–5 Tropfen Bariumchloridlösung (BaCl₂) zu jedem Reagenzglas getropft. Die Gläser werden kurz geschwenkt und das Ergebnis optisch miteinander verglichen.

    - *Beobachtung:*
      - *Reagenzglas 1 (Na₂SO₄ - Positivkontrolle):* Es bildet sich sofort eine deutliche milchig-weiße Trübung (feiner weißer Niederschlag von BaSO₄), die auch im Sauren stabil bleibt.
      - *Reagenzglas 3 (dest. Wasser - Blindprobe):* Die Flüssigkeit bleibt vollkommen klar und farblos; keinerlei Trübung.
      - *Reagenzglas 2 (Testsubstanz):*
        - *Ergebnis A (Sulfat enthalten):* Es bildet sich ebenfalls eine milchig-weiße Trübung, die exakt wie in Reagenzglas 1 aussieht und säurebeständig ist.
        - *Ergebnis B (kein Sulfat enthalten):* Die Lösung bleibt vollständig klar wie die Blindprobe in Reagenzglas 3.

    - *Funktion der Vergleichsreihe (Positiv- und Negativkontrolle):*
      - *Reagenzglas 1 (Positivkontrolle):* Beweist, dass das Nachweisreagenz (BaCl₂) einwandfrei funktioniert und zeigt das typische Aussehen eines positiven Befunds als direkten Referenzwert.
      - *Reagenzglas 3 (Blindprobe / Negativkontrolle):* Schließt Verunreinigungen des Wassers oder des BaCl₂-Reagenzes aus. Wenn hier eine Trübung auftreten würde, wären die verwendeten Chemikalien verunreinigt und der Test ungültig.
      - *Reagenzglas 2 (Testsubstanz):* Das Ergebnis kann zweifelsfrei durch den direkten Vergleich mit Glas 1 und Glas 3 abgelesen werden.

    - *Erklärung & Reaktionsgleichungen:*
      Sulfationen reagieren mit Bariumionen zu schwer löslichem Bariumsulfat (BaSO₄), das als feiner weißer Feststoff ausfällt:
      - *Ionengleichung:*
        SO₄²⁻ + Ba²⁺ -> BaSO₄↓
      - *Stoffgleichung (Positivprobe):*
        Na₂SO₄ + BaCl₂ -> BaSO₄↓ + 2 NaCl

    - *Bedeutung der Salzsäure (Säurebeständigkeit als Absicherung):*
      Bariumsulfat (BaSO₄) ist das Salz einer starken Säure (H₂SO₄) und löst sich in Salzsäure *nicht* auf.
      - *Stör-Ionen ausschließen:* Bariumcarbonat (BaCO₃) und Bariumsulfit (BaSO₃) sind ebenfalls weiße Niederschläge, lösen sich aber in Salzsäure unter Gasentwicklung (CO₂↑ bzw. SO₂↑) wieder auf:
        BaCO₃↓ + 2 H₃O⁺ -> Ba²⁺ + CO₂↑ + 3 H₂O
        BaSO₃↓ + 2 H₃O⁺ -> Ba²⁺ + SO₂↑ + 3 H₂O
      - -> *Nur eine Trübung, die nach Zugabe von verdünnter Salzsäure bestehen bleibt, beweist sicher Sulfationen (SO₄²⁻)!*

    - *Auswertung der Testsubstanz:*
      - Trübung wie in Glas 1 -> *Sulfationen (SO₄²⁻) positiv nachgewiesen.*
      - Klar wie in Glas 3 -> *Keine Sulfationen (SO₄²⁻) in der Probe vorhanden.*

*** 1.8 Flammenversuch mit energie 
    *Versuch: Flammenfärbung von Metallsalzen (Spektralanalyse als Vorprobe)*

    #+BEGIN_SRC text
      Versuchsaufbau:                       Energieniveauschema (Quantensprung):

           Flamme (z.B. gelb)                    Energie E
               (   )                                 ▲
              (     )                                │     angeregter Zustand (E₁)
             (  ***  )                               ├─────────────────────────────┤
            (  *****  ) Magnesiastäbchen             │              ▲          │   │
            ( ******* )=======|====                  │              │          │   │
             (  ***  )       Substanz                │              │          ▼   │
               |   |         (Salz)                  │   Absorption │  Emission    │
            ┌──┴───┴──┐                              │   thermische │  Lichtquant  │
            │ Brenner │                              │   Energie    │  (Photon)    │
            │  (blau) │                              │   (Brenner)  │  ΔE = h · f  │
            └────┬────┘                              │              │          │   │
                 │                                   │              │          │ ░░░ ──► Flammenfarbe
            ─────┴─────                              │              │          ▼   │     (spezifische
               Sockel                                ├─────────────────────────────┤     Wellenlänge λ)
                                                     │     Grundzustand (E₀)       │
                                                    ─┴─────────────────────────────┴─
    #+END_SRC

    - *Geräte & Chemikalien:*
      Bunsenbrenner, Magnesiastäbchen (oder Platindraht), Kobaltglas, Spatel, Uhrglas, Becherglas; konzentrierte Salzsäure (HCl, ca. 20–30 % zum Reinigen/Ausglühen);
      7 Metallsalze (vorzugsweise leicht flüchtige Chloride):
      Lithiumchlorid (LiCl), Natriumchlorid (NaCl), Kaliumchlorid (KCl), Calciumchlorid (CaCl₂), Strontiumchlorid (SrCl₂), Bariumchlorid (BaCl₂), Kupfer(II)-chlorid (CuCl₂).

    - *Durchführung:*
      1. Das Magnesiastäbchen wird kurz in konzentrierte Salzsäure getaucht und in der heißesten Zone der nichtleuchtenden Bunsenbrennerflamme (rauschende Flamme, ca. 1000–1200 °C) so lange ausgeglüht, bis die Flamme keine Eigenfärbung mehr zeigt.
      2. Das noch warme Stäbchen wird erneut kurz mit Salzsäure benetzt und vorsichtig in das zu untersuchende Salzpulver getippt, sodass wenige Kristalle anhaften.
      3. Das behaftete Stäbchen wird in den äußeren Rand der Flammenbasis gehalten und die auftretende Flammenfärbung mit bloßem Auge beobachtet.
      4. Bei Kaliumsalzen wird die Flamme zusätzlich durch ein blaues Kobaltglas betrachtet.
      5. Vor jeder neuen Probe wird das Stäbchen erneut mit Salzsäure gereinigt und bis zur Farblosigkeit ausgeglüht (oder ein frisches Stäbchen verwendet).

    - *Beobachtungen (Farben der 7 Metallsalze):*
      - *Lithium (Li⁺):* Karminrot (tiefes, leuchtendes Rot)
      - *Natrium (Na⁺):* Intensiv gelb (extrem hell, hält lange an und überdeckt fast jede andere Farbe)
      - *Kalium (K⁺):* Fahlviolett / lila (mit bloßem Auge oft von gelben Na⁺-Spuren überdeckt; durch das blaue Kobaltglas deutlich violett/rotviolett sichtbar)
      - *Calcium (Ca²⁺):* Ziegelrot (orangerot, flüchtig)
      - *Strontium (Sr²⁺):* Scharlachrot / intensiv rot
      - *Barium (Ba²⁺):* Fahlgrün / gelbgrün
      - *Kupfer (Cu²⁺):* Grün bis intensiv blaugrün (smaragdgrün)

    - *Vorgänge auf Teilchen- und Energieebene (Atommodell nach Bohr):*
      #+BEGIN_SRC text
           1. Zufuhr thermischer Energie           2. Spontane Relaxation (Emission)
              (Absorption / Anregung)                 (Rückkehr in den Grundzustand)

              E₁ ───────( e⁻ )───────                 E₁ ─────────────────────
                         ▲                                        │
                         │                                        │  ΔE = E₁ - E₀
                         │ + ΔE (Wärme)                           ▼  wird frei als
                         │                                      ( e⁻ ) Lichtquant
              E₀ ───────( e⁻ )───────                 E₀ ───────( e⁻ )─────── ──► h · f
      #+END_SRC
      - *1. Schritt (Verdampfung & Atomisierung):* In der heißen Brennerflamme verdampft das Metallsalz und dissoziiert in gasförmige Atome bzw. Metall-Ionen.
      - *2. Schritt (Thermische Anregung / Absorption):* Durch Stöße mit hochenergetischen Gasteilchen der Flamme nimmt ein Außenelektron (Valenzelektron) des Metallatoms/Ions thermische Energie auf (ΔE). Es wird aus seinem energetisch tiefsten Niveau, dem *Grundzustand (E₀)*, auf ein höheres, unbesetztes Energieniveau, den *angeregten Zustand (E₁)*, angehoben („Quantensprung nach oben“).
      - *3. Schritt (Lichtemission / Relaxation):* Der angeregte Zustand ist instabil (Lebensdauer ca. 10⁻⁸ s). Das Elektron fällt spontan unter Abgabe der Energiedifferenz wieder auf das niedrigere Niveau (E₀) zurück. Die freiwerdende Energie wird als Lichtportion emittiert: ein einzelnes *Photon / Lichtquant* mit genau dieser Energie ΔE.

    - *Physikalische Gesetzmäßigkeiten & Energiezusammenhang:*
      - *Planck'sche Beziehung:*
        $$\Delta E = E_1 - E_0 = h \cdot f = h \cdot \frac{c}{\lambda}$$
        (h: Planck'sches Wirkungsquantum, f: Frequenz, c: Lichtgeschwindigkeit, λ: Wellenlänge)
      - *Zusammenhang zwischen Energie ΔE und Flammenfarbe:*
        - *Große Energiedifferenz ΔE* -> hohe Frequenz f, kurze Wellenlänge λ -> energiereiches, kurzwelligeres Licht (z. B. violett/blau, wie bei K⁺ oder Cu²⁺).
        - *Kleine Energiedifferenz ΔE* -> geringere Frequenz f, lange Wellenlänge λ -> energieärmeres, langwelligeres Licht (z. B. rot/orangerot, wie bei Li⁺, Sr²⁺, Ca²⁺).
      - *Warum elementspezifisch?* Die Energieniveaus in der Atomhülle sind *gequantelt* und durch Kernladung sowie Zahl der Elektronen für jedes Element absolut einzigartig. Die Elektronen können nur ganz bestimmte Energiesprünge ausführen. Daher sendet jedes Metall-Kation Licht mit diskreten, unverwechselbaren Wellenlängen aus (Linienspektrum als „optischer Fingerabdruck“).

    - *Wichtige Praxishinweise & Störungen:*
      - *Warum Salzsäure (HCl)?* Metallchloride besitzen eine wesentlich höhere Flüchtigkeit als z. B. Oxide, Sulfate oder Nitrate. Durch die HCl wird das Salz an der Oberfläche in das leicht verdampfbare Chlorid überführt.
      - *Warum Kobaltglas bei Kalium?* Natrium ist als Verunreinigung praktisch überall vorhanden (an den Händen, im Staub, im Glas). Wegen der extrem hohen Intensität der gelben Natrium-Doppellinie (589 nm) wird die schwächere violette Kaliumflamme meist vollständig überstrahlt. Blaues Kobaltglas enthält Co²⁺-Ionen, die gelbes Natriumlicht selektiv absorbieren, während violettes Licht ungehindert durchtritt.
      - *Hinweis vs. Nachweis:* Die Flammenfärbung ist eine orientierende *Vorprobe* (Hinweis). Bei Stoffgemischen überdecken sich die Farben gegenseitig, weshalb für einen zweifelsfreien Nachweis nasschemische Fällungsreaktionen oder ein Spektroskop erforderlich sind.
